# ДБТ · Самопомощь — Навыки выживания в кризисе и решения проблем

Интерактивное офлайн-веб-приложение (PWA) и комплект карманных печатных буклетов формата A5 по модулям **«Стрессоустойчивость»** и **«Эмоциональная регуляция»** диалектической поведенческой терапии (ДБТ) Марши Линехан.

Проект создан как бережный, практичный и автономный инструмент самопомощи: от экстренного снижения накала в остром кризисе до пошагового изменения проблемной ситуации, когда кризис уже позади.

🌐 **Рабочая версия:** [auroraultima.github.io/dbt](https://github.io)

---

## Содержание комплекса

Приложение объединяет четыре навыка в единую пошаговую цепочку по шкале накала эмоций (`СТОП → ТРУД → ЗА/ПРОТИВ → РЕШЕНИЕ ПРОБЛЕМЫ`):

1. **ТРУД (`TIPP`) — телесная скорая помощь (накал 8–10 из 10)**
   * **Т**емпература (рефлекс погружения в холодную воду).
   * **Р**елаксация (парная мышечная релаксация).
   * **У**пражнения (короткая интенсивная нагрузка для сброса адреналина).
   * **Д**ыхание (ритмичное дыхание с удлинённым выдохом).
2. **СТОП (`STOP`) — экстренный тормоз между импульсом и действием (накал 5–7 из 10)**
   * **С**топ (физическая остановка и замирание).
   * **Т**олько шаг назад (выход из ситуации на безопасную дистанцию).
   * **О**смотрись (возвращение в реальность и отделение фактов от мыслей).
   * **П**оступай осознанно (выбор действия из «мудрого разума»).
3. **ЗА / ПРОТИВ (`Pros & Cons`) — взвешивание цены импульса (накал 5–7 из 10)**
   * Четырёхквадратная матрица последствий (краткосрочная выгода против долгосрочной цены срыва и удержания).
4. **РЕШЕНИЕ ПРОБЛЕМЫ (`Problem Solving`) — изменение ситуации (накал 0–4 из 10)**
   * Полный 7-шаговый алгоритм Марши Линехан из модуля эмоциональной регуляции (описание события, проверка фактов, постановка простой цели, мозговой штурм, выбор решения, первый шаг и оценка итога).

## Ключевые функции и возможности

### Интерактивная экранная версия
* **Адаптивная светлая и тёмная тема:** интерфейс автоматически подстраивается под тему устройства (`prefers-color-scheme`), используя мягкую тёмно-графитовую палитру для бережной работы в стрессе и ночью (при печати страница автоматически возвращается к экономичному светлому режиму).
* **Экстренный навигатор «Накрывает сейчас» / «Шаги разбора»:** плавающая кнопка быстрого доступа в один тап открывает меню шагов без лишнего текста.
* **Встроенные визуальные таймеры и тренажёры:**
  * Таймер погружения (30 сек) для шага «Температура».
  * Интерактивный дыхательный тренажёр с анимацией вдоха и удлинённого выдоха.
  * Пошаговый таймер парной мышечной релаксации по 16 группам мышц.
  * Таймер паузы и замирания, плюс тренажёр «Факт или мысль?» для навыка «СТОП».
  * Интерактивный конструктор матрицы 2×2 для навыка «За / против» с автоматической сводкой.
  * Пошаговый конструктор разбора ситуации по 7 шагам для навыка «Решение проблемы» с проверкой критериев и экспортом плана.
* **Шкала накала 0–10:** интерактивный ползунок с мгновенной рекомендацией, какой навык сейчас доступен.
* **Персональная карточка на кризис и дневник практики:**
  * Поля для заполнения ранних признаков, первого шага и контактов поддержки.
  * Фиксация уровня накала «до» и «после» применения навыка.
  * **100% приватность:** все личные записи хранятся исключительно локально в памяти устройства (`localStorage`) и никуда не передаются.
  * Экспорт в буфер обмена в один клик («Скопировать карточку» и «Скопировать для терапевта»).

### Печатные буклеты (PDF A5)
* Для каждого навыка автоматически генерируется готовый к двухсторонней печати буклет формата A5:
  * **8 страниц:** `trud.pdf`, `stop.pdf`, `pros_cons.pdf`.
  * **11 страниц:** `problem_solving.pdf`.

### Установка как мобильного приложения (PWA) и офлайн-режим
* **Полная автономность (`sw.js`):** Service Worker кэширует все страницы, иконки и PDF-файлы при первом визите. Приложение мгновенно открывается и работает в авиарежиме без доступа к сети.
* **Нативный вид на смартфоне (`manifest.json`):** устанавливается на главный экран Android и iOS как полноценное приложение без адресной строки браузера.
* **Self-contained сборка:** все шрифты (`PT Sans`, `PT Serif`), стили и скрипты вшиты непосредственно в HTML-файлы при сборке — страницы не зависят от внешних CDN.

## Архитектура и сборка проекта

Проект построен по принципу единого источника данных (Single Source of Truth): весь текст хранится в Python-словарях, из которых скрипты одновременно собирают и веб-версию, и печатные PDF.

```text
├── content.py        # Единая база текстов, шагов, предупреждений и акцентных палитр
├── build_html.py     # Генератор self-contained HTML-страниц (index, trud, stop, pros_cons, problem_solving)
├── build_pdf.py      # Генератор печатных PDF-буклетов формата A5 (на базе ReportLab)
├── make_icon.py      # Генератор иконок приложения (icon.png) и фавиконки (favicon.png)
├── manifest.json     # Манифест веб-приложения (PWA)
├── sw.js             # Service Worker для офлайн-кэширования и автообновления
└── assets/
    ├── app.css       # Адаптивные стили, светлая и тёмная палитры, стили печати
    ├── app.js        # Логика таймеров, матрицы 2×2, 7 шагов разбора, дневника и localStorage
    └── *.woff2/.ttf  # Локальные шрифты PT Sans и PT Serif
```

### Как пересобрать файлы после редактирования текстов
Требуется Python 3 и библиотеки `reportlab` (для PDF) и `pillow` (для иконок):

```bash
pip install reportlab pillow
python build_html.py   # Пересобрать все HTML-страницы
python build_pdf.py    # Пересобрать все PDF-буклеты A5
python make_icon.py    # Пересоздать icon.png и favicon.png
```
